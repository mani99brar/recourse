# AI use: shared core

Everything in this area was written by Claude (Anthropic, Opus 5.5) running as a coding agent in
this repo, and committed through `ops/scripts/commit.sh`. A person has not yet reviewed it line by
line. Each file below says how its content was produced and what checks it.

| Files | How it was made | Checked by |
|---|---|---|
| `package.json`, `pnpm-workspace.yaml`, `tsconfig.base.json`, `.gitignore`, `.env.example` | Written by the agent. Versions are exact pins. | `pnpm install` under the suite lock; `.env.example` is compared with `ENV_NAMES` in `packages/shared/test/params.test.ts` |
| `pnpm-lock.yaml` | Generated by pnpm 12.8.1 | `pnpm install` reports the lockfile up to date |
| `package.json` of the other eleven workspace packages (dependency lists only) | Written by the agent | the install links each workspace package |
| `contracts/foundry.toml`, `contracts/remappings.txt` | Written by the agent | `forge build` and `forge test --match-path 'test/shared/*'` |
| `contracts/src/shared/*.sol` | Written by the agent | `contracts/test/shared/*.t.sol` (layout, decode statuses, two 10,000-run fuzz tests, the shared vectors) |
| `packages/shared/src/*.ts`, `src/node/*.ts` | Written by the agent | `packages/shared/test/*.test.ts` |
| `packages/shared/src/abi/erc8004.ts` | Written by the agent | every selector and event topic was matched against the runtime bytecode of the deployed Hedera testnet implementations |
| `packages/shared/src/abi/kleros.ts`, `src/abi/ccip.ts` | Generated by a small agent-written script from the ABIs shipped in `@kleros/kleros-v2-contracts` 0.12.0 and `@chainlink/contracts-ccip` 2.0.0 | `test/abi.test.ts` checks each item equals the package item; a deliberate one-field change was seen to fail it |
| `packages/shared/vectors/fault-rule.json` | Written by a second Claude agent from the rule text alone, without seeing the rule code | `test/faultRule.test.ts` runs every row against `runFaultRule` |
| `packages/shared/vectors/ids.json`, `codec.json` | Expected values computed with Foundry `cast` (`abi-encode`, `keccak`) | read by both the TypeScript tests and `contracts/test/shared/SharedVectors.t.sol` |
| `packages/shared/vectors/hashing.json` | Digests computed with `sha256sum` over the exact bytes | `test/hashing.test.ts` |
| `packages/shared/vectors/settle.json` | Worked out by hand from the settle table | `test/settle.test.ts` |
| `packages/shared/vectors/addresses.json`, `params.json` | Written out from the TypeScript address book and params | `SharedVectors.t.sol` checks the Solidity constants equal them |
| `docs/spec/interfaces.md` | Written by the agent. The contract sections that other areas own were copied from those areas' interface files at the commits the change log names | read against the code it names |

Keys: the loaders were tested with keystores generated inside the tests. The real keystores were
decrypted once to confirm each one yields its expected address. Only the match result was printed,
never a key or a password.
